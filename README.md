# 개미 투자전략실 — 주식 퀀트 스크리너

첨부 참고 화면을 기준으로 다시 만든 **독립형 스크리너**입니다. 이전 종합 분석·수급·뉴스·포트폴리오 메뉴는 제거했습니다. 기존 버전은 Git 이력에서 확인할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run test.py
```

실행 코드는 `test.py` 하나입니다. Streamlit 배포의 Main file path를 유지합니다.

## 화면

짙은 남색 배경, 얇은 브랜드 바, 상단 도구 모음, 가로 마켓 탭, 조건별 필터, 3열 종목 카드로 구성합니다. 카드에는 코드·이름·확정 종가·등락률·점수·최근 가격 추이·RSI·MDD·거래량·5대 조건을 표시합니다. 상세 버튼을 누르면 매매 타이밍과 조건별 평가가 모달로 열립니다. 작은 화면에서는 열이 재배치됩니다.

- 마켓: 코스피 시총 상위100 / S&P500 / 나스닥100. 가상화폐 제외.
- 필터: 전체·상승 다이버전스·하락 다이버전스·5개 충족·S등급·진입 검토·거래량 급증.
- 도구: 자동 분석 켜기/끄기·종목 추가·전략 설명서·즉시 갱신·검색·정렬·개별 조건 선택·CSV다운로드.
- 상세: 차트 없이 진입·목표·손절·손익비 4개 카드, 5대 조건, 실제 8개 채점 항목의 4개 그룹별 평가, 신호 근거.

## 데이터와 판단

실시간 체결가가 아닌 최근 확정 일봉을 사용합니다. 당일 봉은 보수적으로 제외합니다. 최대 4종목을 병렬 분석하며 완료된 결과부터 표시합니다. 결과 없이 4종목이 실패하면 새 요청을 잠시 중단합니다. 오류를 가짜 시세로 대체하지 않습니다. 전체 목록 조회 실패 시 주요 종목 표본임을 표시합니다. 코스피 시총상위100은 공식 KOSPI100 지수와 다를 수 있습니다.

5대 조건 중 기업 흑자 대신 거래량 회복을 사용합니다. 재무 조회·기업 가치 평가 없이 기술 지표로만 선별합니다. S등급과 손익비2 이상 진입 검토는 서로 다릅니다. MDD는 최대756거래일 표본이며 손실의 한도가 아닙니다. 자체 조건식의 수익성은 검증되지 않았습니다. 자세한 산식은 [MODEL_METHODOLOGY.md](MODEL_METHODOLOGY.md)를 참조하십시오.

```bash
pip install pytest
python -m pytest tests -q
```

검증은 합성 데이터 기반이며 외부 데이터 공급원의 연결 성공을 보장하지 않습니다.

## 성능과 저장

화면 실행 경로에서 네트워크 요청을 기다리지 않고 작업 풀에 넘깁니다. 활성 화면은 1초마다 완료 상태를 확인합니다. 중복 코드와 동시 요청을 합치고, 진행률은 고유 종목의 완료/실패 수로 산정하여 0~100% 범위를 유지합니다.

같은 거래소 현지 날짜의 결과는 프로세스 메모리와 서버 임시 디스크에서 재사용합니다. 탭 전환·재접속 시 이미 분석한 종목을 다시 수집하지 않습니다. 즉시 갱신은 선택한 시장만 무효화합니다. 일시 오류는 120초 뒤 재시도할 수 있습니다. 서버 교체/재배포로 임시 저장이 사라지거나 날짜가 바뀌면 최초 조회가 다시 필요합니다. 여러 서버 간 캐시는 공유되지 않습니다.

자동 분석을 끄면 새 요청만 중단하며 진행 중인 요청은 완료될 수 있습니다. 전체 시장을 계속 분석하려면 활성 화면이 필요합니다. 별도 예약 수집기는 아닙니다. 최초 수집 속도는 데이터 공급원의 응답과 제한에 영향을 받으며, 병렬화가 일정 배수의 실서비스 속도를 보장하지 않습니다.
