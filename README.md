# 개미 투자전략실 V4

한국·미국 종목 분석을 중심으로 시장 상황판, 전조 레이더, 섹터 표본, 투자자 수급,
뉴스·공시, 보유 종목과 관찰 신호 성과를 연결하는 개인용 주식 터미널입니다.
기존 다크 테마와 종목 분석·달리는 말·과대낙폭·백테스트를 유지합니다.

## V4: 조건부 진입 가이드

미국 종목 정밀 분석은 **분할 진입 검토 / 눌림 대기 / 돌파 확인 / 관망**을 먼저 안내합니다. 확정 일봉의 추세·모멘텀·거래량·지지와 저항으로 검토 가격, 눌림 구간, 돌파 구간의 손절선과 손익비를 비교합니다. 선택적으로 직접 입력한 가격에서도 검토할 수 있습니다. 실시간 시세가 아닌 최근 확정 일봉 기준입니다.

불러오지 못하던 기업 실적·가치 카드와 미확인 재무 항목, 해당 화면의 재무 조회 요청을 제거했습니다. yfinance 설치가 필요하지 않습니다. 중장기 가격 팩터와 상세 기술 해석은 펼쳐서 확인합니다.

BlackRock의 공개 모멘텀·위험 개념을 참고하되 진입 임계값은 앱의 자체 규칙입니다. ARK의 기업 가치 평가를 가격 데이터만으로 재현하거나 두 기관의 매수가를 표시하지 않습니다. 관측 저항이 없는 경우의 2R 관리선은 가정이며 진입 조건 충족 근거로 사용하지 않습니다. 계산식은 [MODEL_METHODOLOGY.md](MODEL_METHODOLOGY.md)에 공개합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run test.py
```

Python 3.12 권장. **실행 파일은 `test.py` 하나**입니다.
기존 Streamlit 배포의 Main file path는 `test.py`로 유지하십시오.
GitHub의 `requirements.txt` 변경 사항도 함께 반영되어야 합니다.

## 메뉴와 사용 순서

1. **시장 상황판**: 메뉴 진입 시 지수를 자동 조회하고 최근 확정 일봉 기준 종가·온도와 자동 선별 표본을 표시합니다. 지수 실패 시 Yahoo 일봉을 대체 조회합니다.
2. **급등 전조**: 메뉴를 열면 자동으로 4종목씩 분석합니다. 별도 종목 입력이나 시작 버튼은 필요 없습니다. 선별 근거와 지지선·돌파 기준선·손절 참고선을 표시합니다.
3. **섹터 순환**: 같은 날짜·같은 구성 종목들의 20일선 상회 비율과 5일 상승 참여 확산을 자동 비교하고 조건 충족 종목을 추립니다.
4. **수급 추적**: 한국 종목 중 실제 외국인·기관 양매수 지속 조건을 충족한 종목을 자동 표시합니다. 개별 조회 및 CSV 대체 입력은 기존대로 가능합니다. 미국 일별 기관 수급은 미제공입니다.
5. **뉴스·공시**: 기사 원문 링크와 표현 단서, 설정된 경우 DART/SEC 공시를 조회합니다.
6. **내 종목**: 수량·평단·목표·손절 기준을 입력하고 확정 종가 기준 손익을 갱신합니다.
7. **백테스트·성과**: 기존 전략 검증과 기록 이후 5/10/20거래일 성과를 구분해 확인합니다.

종목 상세의 `기존 종목 분석으로 이동` 버튼으로 기존 정밀 분석을 여실 수 있습니다.

레이더의 점수 변화는 전 거래일 대비 변화입니다. 장중 스냅샷 사이의 변화가 아닙니다.

## 개인 기록 보관

보유 종목과 신호 기록은 **현재 세션에만 보관**합니다. 새 세션이나 서버 재시작 전에
`보유 종목·신호 JSON 백업`을 내려받아 주십시오. JSON 복원 시 검증 후 병합하며,
중복된 종목/신호는 현재 세션의 값을 유지합니다. 자동 기록은 최근 5,000개까지 보관합니다.

개인 데이터는 공개 GitHub 저장소에 업로드하지 마십시오. 서버에서 사용자 간 공유
DB로 저장하지 않으므로 다른 방문자의 보유 종목이 화면에 섞이지 않습니다.

## 예약 스캔 범위

`이 화면이 열려 있는 동안 자동 진행`은 **급등 전조 화면이 활성화된 동안만**
1분마다 배치를 처리합니다. 선택 예약 시각은 거래소 현지 09:30/11:00/14:00/한국 15:30·미국 16:00이며,
평일 해당 시각부터 5분 안에 실행합니다. 휴장일은 별도로 판별하지 않습니다.
먼저 한 번 스캔을 시작해야 다음 예약에 같은 목록을 다시 사용할 수 있습니다.

현재 데이터는 현지 당일 봉을 제외한 확정 일봉입니다. 같은 거래일 자료라면 장중에
다시 조회해도 점수가 같습니다. 브라우저를 닫아도 계속 실행되는 실시간 자동매매나
백그라운드 알림 서비스는 아닙니다.

## 공시 자동 수집 설정 (선택)

Streamlit의 **Secrets**에 본인의 값을 설정합니다. 저장소 파일에는 넣지 마십시오.

```toml
DART_API_KEY = "본인이 발급받은 OpenDART 인증키"
SEC_USER_AGENT = "본인의 앱 이름과 연락 이메일"
```

- OpenDART: 회사 고유번호 매핑 후 최근 90일 공시 목록을 조회합니다.
- SEC: ticker/CIK 매핑 후 최근 공시 목록을 조회합니다.
- 설정이 없거나 공급원 접근이 실패하면 사유와 공식 사이트를 표시합니다.
- 뉴스 해석은 제목의 표현 단서입니다. 생성형 AI 원문 분석 기능은 아직 연결하지 않았습니다.

## 신호 성과의 해석

전조 75점 이상이고 과열 감점이 없으면 자동으로 관찰 기록을 남깁니다.
직접 기록한 관심 신호도 포함됩니다. 동일 모델/시장/종목/기준일은 중복 기록하지 않습니다.

성과는 **기록일 다음 거래일 이후 첫 거래 가능한 시가 → 보유 N번째 거래일 종가**로
계산하며 양방향 비용을 반영합니다. 오래된 신호를 오늘 기록해도 과거 상승분을
내 성과에 넣지 않습니다. 아직 N거래일이 지나지 않은 신호는 평균에서 제외합니다.
실제 체결·배당·환율·세금, 선택편향과 동일 종목 신호의 비독립성에 유의하십시오.

## V2.1 자동 선별 규칙

**특정 증권사 내부 규칙이 아닌, 공개 지표를 조합한 이 앱의 조건식입니다.** 점수 순으로 무조건 종목을 채우지 않습니다. 조건 충족과 데이터 미확인을 구분합니다.

| 조건 | 계산식·임계값 |
|---|---|
| 공통 추세 | 종가>MA20, MA20이 5일 전보다 상승, MA20 이격 0~10%, RSI 45~75 |
| 거래 동반 돌파 | 종가>직전 20일 고점, 전일 종가보다 상승, 거래량/직전 20일 평균≥1.5 |
| 압축 후 돌파 | 전일 BB 폭이 그 이전 60일 하위 25% + 거래 동반 돌파 |
| 거래대금 회전율 급증 | 실제 거래대금/같은 날 시가총액×100≥1%, 직전 20일 평균의 2배 이상 |
| 양매수 지속 | 최근 5일 외국인·기관 각각 누적 양수, 양매수≥3일, 최근 연속 양매수≥2일, 합산 순매수/5일 거래량≥1% |
| 섹터 확산 | 같은 날짜 2종목 이상·정의 구성 75% 이상, MA20 위 비율≥60%, 5일 상승 비율≥60%, 동일 종목 MA20 상회 비율이 5일 전보다 증가 |

급등 전조는 공통 추세와 돌파·회전율·양매수 중 하나 이상을 요구합니다. 수급 추적은 양매수 지속 조건으로 독립 선별합니다. 섹터 종목은 확산 섹터 안에서 공통 추세를 충족한 종목입니다. 전조 점수는 보조 정렬 기준이며 충족 확률이 아닙니다.

- **범위:** 정의된 테마·주요 종목 표본. 한국 시장 스냅샷 확보 시 그 표본 안의 시총 1,000억원 이상 거래활동 상위 40개를 추가합니다. 전 종목 스캔으로 표시하지 않습니다. 이 후보군 구성에만 종가×거래량을 사용하며 실제 거래대금 회전율은 별도로 계산합니다. 직접 입력·전체 목록 스캔은 선택 기능으로 유지합니다.
- **자료:** 최근 확정 거래일 비교. 거래소 현지 오늘 날짜 봉을 보수적으로 제외하므로 당일 장 마감 직후에도 전 거래일 기준입니다. 7일 초과 오래된 일봉 제외, 서로 다른 기준일 비교 제외. KRX 수집 가능 여부를 한 번 확인한 뒤 실제 Amount·MarCap 21일을 사용합니다. 누락 시 회전율 미확인. 미국 일별 기관 수급과 시가총액 시계열은 연결되지 않아 해당 조건을 사용하지 않습니다.
- **타점:** 지지선=직전 10일 저점, 돌파선=직전 20일 고점, 손절 참고선=지지선−0.5 ATR(14). 당일 고저가를 과거 돌파 기준에 포함하지 않습니다. 손절값이 0 이하이면 미확인. 호가 단위·체결·갭·비용을 반영한 주문 가격이 아닙니다.
- **운영:** 활성 화면에서 3초 주기로 다음 4종목을 처리하고 결과를 추가합니다. 공급원 지연 시 배치 완료까지 더 걸릴 수 있습니다. 첫 12종목이 모두 실패하면 요청을 중단하고 실패를 표시합니다. 날짜 변경 시 새로 시작하며 수동 새로고침도 가능합니다. 브라우저를 닫은 동안의 서버 작업은 아닙니다.
- **실패 구분:** 조회 실패, 분석 중인 일부 결과, 조건 충족 없음, 정상 완료를 구분합니다. 공급원 장애를 가짜 시세·수급·종목으로 보충하지 않습니다. 현재 세션의 자동 결과는 다른 메뉴에서 공유합니다.

### 지표 출처

- [Fidelity — Bollinger Band Width](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/bollinger-band-width): 밴드폭은 변동성 압축 확인에 사용하며 방향 자체를 보장하지 않습니다.
- [Fidelity — ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr): 갭을 포함한 변동성 측정. 위 손절 배수는 앱의 자체 규칙입니다.
- [FinanceDataReader KRX 구현](https://github.com/FinanceData/FinanceDataReader/blob/master/src/FinanceDataReader/krx/data.py): KRX 일봉의 실제 Amount·MarCap 열을 사용합니다. 공급원 인증·장애·스키마 변경에 따라 조회가 실패할 수 있습니다.
- [KRX 투자자별 거래실적](https://data.krx.co.kr/contents/MDC/MDI/outerLoader/index.cmd?locale=ko_KR&screenId=MDCSTAT022): 거래수량과 거래대금은 서로 다른 단위입니다. 앱의 일별 투자자 수량은 네이버 금융 제공값을 사용합니다.
